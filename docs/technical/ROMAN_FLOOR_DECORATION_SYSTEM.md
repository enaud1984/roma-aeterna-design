# Pavimenti decorativi romani

Il piano pavimentale supporta:

- `OpusSigninum`;
- `GeometricMosaic`;
- `SimplePolychromeMosaic`;
- `OpusSectileInspired`;
- `BrickFloor`;
- `StoneFloor`;
- `PackedEarth`;
- `ProductiveFloor`;
- `ThermalFloor`.

La scelta dipende da funzione e ricchezza. Case povere usano terra o laterizio; la domus media usa opus signinum o mosaico geometrico; terme e officine ricevono superfici dedicate. `OpusSectileInspired` è una rappresentazione geometrica tecnica e non implica marmo autentico.

Il pavimento è composto da due campate contigue, riusa una Material Instance per tipo e conserva fallback tecnici.
