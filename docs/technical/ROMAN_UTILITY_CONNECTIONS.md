# Connessioni alle utilities

`UtilityConnection` collega edifici, nodi idrici, drenaggi, fogne e fonti di calore. Le API calcolano domanda relativa di acqua, drenaggio, calore e capacità di deposito.

La validazione controlla identificatori, connessioni richieste e presenza delle reti; non simula pressione, portata o termodinamica reale.
