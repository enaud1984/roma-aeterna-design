# Glossario latino–italiano

## Scopo

Fissare significati operativi dei termini latini evitando traduzioni moderne fuorvianti.

## Descrizione

Le equivalenze sono guide contestuali, non identità lessicali. Forma, periodo, genere testuale e area possono cambiare significato.

## Ambito

Termini prioritari per Pompei, società, diritto, economia, religione, città ed esercito.

| Latino | Resa operativa | Nota e rischio |
|---|---|---|
| *aedes* | edificio/sede sacra; talvolta casa | non sempre sinonimo tecnico di *templum* |
| *ager* | territorio/campagna/terra | specificare regime e località |
| *auctoritas* | influenza/autorità riconosciuta | non coincide automaticamente con potere legale |
| *caupona* | esercizio di ospitalità/ristoro | uso e reputazione dipendono dal contesto |
| *civitas* | cittadinanza/comunità civica | non “città” in ogni occorrenza |
| *cliens* | cliente in relazione patronale | non cliente commerciale moderno |
| *collegium* | associazione/corpo riconosciuto | non sindacato moderno universale |
| *contubernium* | unione/coabitazione priva di pieno matrimonio romano, anche contesto militare | non tradurre sempre matrimonio |
| *decurio* | membro dell'ordine/consiglio locale; anche rango in altri contesti | disambiguare istituzione |
| *domus* | casa, household o sede sociale | non solo villa urbana di élite |
| *familia* | insieme sotto autorità/household, anche persone schiavizzate, secondo contesto | non equivale a famiglia nucleare |
| *forum* | spazio civico/mercantile/giudiziario | funzioni dipendono dalla città |
| *imperium* | potere di comando magistratuale/militare | non sinonimo semplice di Impero territoriale |
| *insula* | isolato urbano o edificio, secondo contesto | a Pompei la numerazione è moderna |
| *ingen(u)us* | nato libero | distinto da *libertus* |
| *libertus/liberta* | persona liberata in rapporto all'ex dominus/patronus | “liberto” non significa pienamente privo di obblighi |
| *libertinus* | condizione/origine libertina, uso variabile | non intercambiabile sempre con *libertus* |
| *munus* | obbligo, servizio, dono o spettacolo | evitare una sola traduzione |
| *ordo decurionum* | consiglio/ordine dirigente municipale | non senato nazionale moderno |
| *patria potestas* | potere giuridico del paterfamilias | non “autorità paterna” moderna generica |
| *patronus* | patrono/protettore con relazioni giuridiche o sociali | distinguere patronato di liberti, clienti e cause |
| *peculium* | patrimonio gestito ma giuridicamente dipendente | non piena proprietà dello schiavo/figlio |
| *pietas* | condotta doverosa verso dei, famiglia e comunità | non semplice pietà emotiva |
| *populus* | corpo civico/popolo | non popolazione indistinta in ogni testo |
| *res publica* | affare/comunità pubblica, stato | non sempre “Repubblica” come periodo |
| *servus/serva* | persona schiavizzata nel lessico antico | nei testi moderni preferire formula che mantenga la persona |
| *taberna* | spazio commerciale/artigianale o bottega | non necessariamente taverna |
| *templum* | spazio ritualmente delimitato; per estensione contesti sacri | non ogni edificio di culto è tecnicamente templum |
| *thermopolium* | termine antico raro applicato modernamente a esercizi con bancone | evitare “fast food romano” come etichetta canonica |
| *triumphus* | trionfo autorizzato a Roma | distinto da *ovatio* e celebrazioni locali |
| *vicus* | quartiere/strada/villaggio secondo contesto | verificare uso locale |
| *villa* | complesso rurale/residenziale-produttivo | non villa moderna soltanto ricreativa |

## Regole editoriali

Prima occorrenza in corsivo con spiegazione; forme italianizzate solo se non cancellano distinzioni; lemma latino nei dati storici; varianti e abbreviazioni epigrafiche documentate.

## Criteri di accettazione

Ogni termine di sistema ha definizione contestuale e rimando; traduzioni contestate sono revisionate da latinista/epigrafista.

## Definition of Done

Corpus prioritario coperto, lemmi collegati ai documenti consumer, forme UI e audio approvate.
