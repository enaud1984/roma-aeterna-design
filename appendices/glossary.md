# Glossario

Termini di progetto, da non usare come equivalenti senza una decisione.

| Termine | Definizione operativa |
|---|---|
| Agent/NPC | persona simulata; “NPC” non implica subordinazione narrativa al player |
| Agency situata | scelta significativa dentro vincoli materiali, sociali e storici |
| Aggregazione | rappresentazione compatta che conserva invarianti rilevanti |
| Canone | stato/fatto che il mondo considera avvenuto, distinto dalle credenze |
| Causal chain | legami registrati tra condizioni, evento ed effetti |
| Città viva | sistema urbano di flussi, ritmi e decisioni autonome |
| Cohort | insieme aggregato di persone non ancora individualizzate |
| Diegetico | appartenente al mondo percepito dai personaggi |
| Evento | cambiamento datato con attori, luogo, cause ed effetti |
| H1–H4 | classi di certezza/trasformazione storica definite in GOV-DOC-001 |
| Household | unità domestica/economica, non necessariamente famiglia moderna |
| Invariante | condizione che resta vera attraverso aggiornamenti e livelli |
| Ledger | registro interrogabile di trasferimenti o cause |
| Living world | mondo con continuità causale indipendente dal player |
| Provenienza | collegamento tra affermazione/asset/regola e fonte o decisione |
| Raffinamento | passaggio da stato aggregato a rappresentazione più dettagliata |
| Reputazione | credenza contestuale di una comunità su un soggetto e dominio |
| Situation | configurazione autoriale aperta che può evolvere senza player |
| Storylet | modulo narrativo attivato da condizioni sistemiche |
| Vertical slice | porzione rappresentativa che prova pipeline e qualità target |

Termini storici come *familia*, *domus*, *insula*, *collegium*, *patronus*, *cliens*, *libertus* e *pietas* riceveranno voci filologiche dopo la definizione cronologica; non vanno tradotti automaticamente con categorie moderne.
